Aula 2 - Conhecer o usuário

Você não é o usuário. Antes de desenhar, descubra quem vai usar, onde e para que

Passo 1 - Pesquisa simples (sem gastar nada)

Conversar com 3 a 5 pessoas: "Como você faz isso hoje? O que atrapalha?"

Observar a pessoa realizando a tarefa, sem ajuda

Questionário curto com 5 perguntas

Passo 2 - Persona

Persona é um personagem que representa um grupo de usuários

Campo Exemplo (app de irrigação IoT)
Nome / Idade Dona Marte, 58
Contexto Horta no quintal, usa celular simples, sol forte
Objetivo Saber se a planta precisa de água
Dores Letras pequenas, muitos menus, termos técnicos

Passo 3 - Tarefas (user stories)

Como [quem], quero [fazer o que], para [qual benefício]

Ex: Como Dona Marta, quero ver se o solo está seco, para decidir se ligo a bomba

Passo 4 - Jornada do usuário

Liste cada etapa e o que a pessoa sente

Etapa Ação Emoção Oportunidade
1. Abir o app Tocar no ícone Curiosa Abrir direto no painel
2. Ver umidade Lê o número Confusa (%?) Usar cor e palavra: "Seco"
3. Ligar bomba Procura o botão Insegura Botão grande + confirmação
