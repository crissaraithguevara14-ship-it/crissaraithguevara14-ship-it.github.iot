Aula 1 - O que é UX e UI?

UX (User Experience - Esperiência do Usuário)

É como a pessoa se sente ao usar o produto do começo ao fim se consegue fazer o que quer, rápido, sem erro e sem frustração

UI (User Interface - Interface do Usuário)

É a parte visual e de interação: botões, cores, textos, ícones telas.

UX UI
Pergunta "Funciona bem para a pessoa?" "Como isso aparece e funciona?
Foco Fluxo, necessidade, facilidade Layout, cor, tipografia, componentes
Exemplo Ligar a luz em 2 toques O botão é grande, claro e muda de cor

Analogia - uma porta: a UI é a maçaneta bonita; a UX é acertar se a porta abre para o lado certo e se dá para abrir com as mãos

Design vs. decoração

Design bom resolve um problema. Se um elemento não ajuda o usuário a cumprir uma tarefa ele atrapalha

Processo de design (resumo)

1. Entender: quem usa, onde, para que? (pesquisa)

2. Definir: Qual problema vamos resolver? (personas, tarefas)

3. Desenhar: esboço no papel, depois wireframe

4. Prototipar: versão clicável simples

5. Testar: obsservar 3 a 5 pessoas usando

6. Melhorar: corrigir e repetir
